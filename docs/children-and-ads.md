# 兒童政策與 AdMob 設定注意事項

語言學習 App 很容易被 Google 認定為「可能吸引兒童」。上架前請先決定**目標年齡層**，再依下表調整。

## 1. Play Console「目標對象和內容」怎麼選
| 你的選擇 | 後果 |
|---|---|
| 只選 13 歲以上（建議初期這樣做） | 不需加入 Families 計畫。但若畫面、圖示、文字明顯吸引兒童（卡通、童趣用語），Google 仍可能要求你說明或改為包含兒童。 |
| 包含 13 歲以下 | 必須遵守 **Families 政策**（見下方），廣告與登入都有限制。 |

**降低被誤判的方法**：商店圖文避免卡通化、童話風；描述寫明「適合國高中以上與成人」；題目內容以成人情境（職場、旅遊）為主。

## 2. 若目標族群包含兒童（Families 政策重點）
- 只能使用 **Families 自我認證的廣告 SDK**（AdMob 有在名單中）。
- 程式設定：把 `gradle.properties` 改成 `adsChildDirected=true`，App 會：
  - `setTagForChildDirectedTreatment(TRUE)`：要求 Google 以 COPPA 方式處理（不做個人化廣告）
  - `setTagForUnderAgeOfConsent(TRUE)`：歐盟 GDPR 未達同意年齡的處理
  - `maxAdContentRating = G`（`adsMaxContentRating=G`）
- **移除廣告 ID 權限**：在 `AndroidManifest.xml` 把那行 `AD_ID ... tools:node="remove"` 取消註解。
- 廣告不得具欺騙性、不得干擾正常使用：本 App 的插頁廣告只在一輪結束後出現且有頻率上限，獎勵廣告完全由使用者自選 —— 這個設計符合要求，**不要改成強迫觀看**。
- Google 登入必須是選擇性的（本 App 已是），且不得要求兒童提供個人資料。請再確認最新 Families 政策對第三方登入的規範。
- 隱私權政策第 7 段選「包含兒童」的版本。

## 3. 「混合對象」（兒童與成人都有）的進階做法
可在首次開啟時加入「中性年齡詢問畫面」，依使用者回答的年齡決定是否套用兒童設定（需要改程式，目前未實作）。

## 4. AdMob 後台要設定的
1. **應用程式 → 應用程式設定**：連結 Play 商店後，依目標族群設定。
2. **封鎖控制項 → 內容分級上限**：建議設為 **G**（與程式的 `adsMaxContentRating` 一致）。
3. **封鎖控制項 → 敏感類別**：可封鎖約會、賭博、酒精等不適合學生的類別。
4. **隱私權與訊息 → GDPR / 美國州法規訊息**：建立同意訊息（App 已整合 UMP，會自動顯示）。
5. **app-ads.txt**：上架後在你的開發者網站根目錄放置 app-ads.txt（AdMob 後台會給內容），避免收益受影響。
6. 開發時**一律用測試 ID**（本專案 debug 版強制使用測試 ID）；用正式 ID 點自己的廣告可能導致帳號被停權。
